# 얼굴 이미지 넣는 곳

파일명은 멤버 id로 저장하세요 (png / jpg / webp 모두 가능).

| 파일명 | 멤버 |
|---|---|
| abyss.png | 차선우 (심연) |
| eclipse.png | 차은결 (일식) |
| comet.png | 한서하 (혜성) |
| mist.png | 서이준 (안개) |
| moon.png | 백유한 (달) |
| aurora.png | 류시온 (오로라) |
| star.png | 이하루 (별) |

- 권장: 티키타 규격 **512×768 (2:3)**, 상반신, 얼굴이 위쪽 1/3 지점에 있는 구도, 어두운 배경
- 여기 넣은 파일은 **미리보기용**입니다. 티키타 공개 소개에 붙여넣을 때는 이미지 **주소(URL)** 가 필요합니다
  → 티키타에 업로드한 이미지에서 우클릭 → "이미지 주소 복사" → `data/faces.json`의 `url` 칸에 붙여넣기
- 얼굴이 없으면 실루엣으로 자리만 잡아 두고 빌드됩니다
