# 달빛 방송부 운영진 매뉴얼

운영진 2명이 이벤트 기간 동안 사용하는 안내서입니다. 모든 운영 명령어 응답은 **나에게만 보이며**, 채널에 게시되는 것은 `/운영 공개`·`/운영 시작` 뿐입니다.

## 운영 명령어

| 명령어 | 용도 |
|---|---|
| `/운영 상태` | 현재 시각(KST), 개막·공개 회차, 참가자 수, **운영 알림**, 최근 해석 실패 질문 |
| `/운영 예약` | 공개 일정표(영상 준비 상태 포함). `회차:5 일시:2026-09-25 18:00` 으로 변경, `일시:삭제` 로 변경 취소 |
| `/운영 공개 대상:회차 번호:N` | N화 수동 공개 (앞 회차가 공개돼 있어야 함, 중복 공개 불가) |
| `/운영 공개 대상:증거 증거:E-05` | 증거를 회차보다 먼저 공개 |
| `/운영 공개 대상:엔딩` | 12화 공개 후 엔딩(진실 공개) 게시 + 정답 보상 정산 |
| `/운영 시작` | 비상시 개막 공지 + 1화 수동 게시. 개막 전이면 `확인:조기 시작` 필요 |
| `/운영 중지` / `/운영 재개` | 자동 공개와 참가자 기능 일시 정지 / 재개 |
| `/운영 테스트` | 채널에 올리지 않는 미리보기: 데이터 점검, 개막·회차·증거·엔딩 미리보기, 질문 테스트(회차 지정), 수사 수첩 |
| `/운영 결과` | 포인트 순위 · `형식:CSV` 결과 파일 · `참가자:@이름` 개인 기록 |
| `/운영 영상 회차:N 링크:URL` | 유튜브(일부 공개) 등 영상 링크 등록. 재배포 없이 바로 반영되고 재시작 후에도 유지(DB). 아직 공개 전인 회차는 공개 때 함께 게시, 이미 공개된 회차는 채널에 영상 링크를 바로 올림. `링크:삭제` 로 취소 |
| `/운영 공지 내용:...` | 이벤트 채널에 방송부 이름으로 공지 게시 (줄바꿈은 `\n`) |

참가자 명령어: `/시작 /사건 /질문 /증거 /조사 /추리 /정답 /진행도 /관계도 /도움말` (이벤트 채널에서만 동작). 공식 게시물의 버튼으로도 모두 이용할 수 있습니다.

## 이벤트 전날(9/23) 체크리스트

1. `python -m bot.cli check` → "이상 없음" 또는 남은 항목이 의도된 것인지 확인
   - 12화 영상(또는 링크), 제목, 포스터, 편성 시각(2화~12화)
2. `python -m bot.cli simulate` → 개막부터 12화까지 게시 순서가 맞는지 확인
3. 봇이 서버에 들어와 있고 `/운영 상태` 가 응답하는지 확인 (테스트 모드 OFF)
4. `/운영 테스트 항목:개막 미리보기`, `회차 미리보기 번호:1` 로 문구 확인
5. `/운영 테스트 항목:질문 테스트 번호:1 질문:반휘혈이 고백을 녹음했나요?` → 1화 기준 "아직 공개되지 않은 정보입니다." 확인
6. 웹 조사실: 운영진 계정으로 로그인 → "이벤트는 09/24(목) 00:00 에 시작됩니다" 배너 확인
7. 서버 시계 동기화(`timedatectl`), 서비스 자동 재시작(systemd) 확인, DB 백업 위치 확인

## 늦은 개막 자동 시작 (`event.auto_start_late`)

`settings.json` 의 `event.auto_start_late: true` 이면, 개막 시각이 지났는데 개막 공지·1화가 아직 없을 때
봇이 켜지자마자 `/운영 시작` 과 똑같이 **개막 공지 + 1화를 한 번만** 게시합니다(영상이 없으면 영상 없이).
`/운영 중지` 상태에서는 동작하지 않고, 이미 게시된 뒤에는 다시 올리지 않습니다.
영상은 준비되면 `/운영 영상 회차:1 링크:...` 로 등록하면 이벤트 채널에 링크가 따로 올라갑니다.

## 자동 공지 · 회차 일괄 공개

- `event.announcements`: `{id, title, body, banner}` 목록. 봇이 켜지면 id 별로 **한 번만** 이벤트 채널에 게시합니다(개막보다 먼저). 새 공지를 올리려면 새 id 로 추가하세요.
- `schedule.release_through: N`: 개막 후 1~N화를 순서대로(20초에 1편) 공개합니다. 이미 공개된 회차는 건너뜁니다. 더 공개하려면 숫자를 올리거나 `/운영 공개` 를 쓰세요.
- 회차 게시물에는 영상을 펼치지 않고 **[영상 보기]** 버튼만 둡니다. 누르면 공개된 회차가 `1화` `2화` … 버튼으로 나오고, 버튼을 누르면 유튜브가 열립니다.

## 영상 (유튜브 일부 공개)

유튜브에 **일부 공개(Unlisted)** 로 올리면 링크가 있는 사람만 볼 수 있고, 디스코드에서 플레이어 미리보기가 붙습니다.
(**비공개(Private)** 는 초대한 계정만 볼 수 있어 참가자가 재생할 수 없으니 반드시 "일부 공개" 로 올리세요.)

1. 유튜브 스튜디오 → 공개 상태 **일부 공개** → 링크 복사 (예: `https://youtu.be/xxxx`)
2. 이벤트 채널에서 `/운영 영상 회차:2 링크:https://youtu.be/xxxx`
3. `/운영 예약` 에서 해당 회차 영상 상태가 "링크" 로 바뀌었는지 확인

## 게임 진행 방법 (참가자)

공식 게시(개막·회차·증거·엔딩·공지)와 참가자 명령어 모두 `#도근고-추리-토론`(1552877179187232798)에서 동작합니다. 채널을 바꾸면(`event.repost_on_channel_change`) 예전 채널에 올라간 공지·개막·회차가 새 채널에 한 번씩 다시 올라갑니다. `event.cleanup_channels` 에 적힌 예전 채널에서는 봇이 올린 글만 한 번 지웁니다(다른 사람 글은 그대로). 응답은 본인에게만 보입니다.

- `/시작` 또는 [수사 시작하기] → 수사 수첩
- `/질문 내용:...` → YES / NO / 관계없음 / 아직 공개되지 않은 정보
- `/증거`, `/조사 증거:E-01` → 공개된 증거 조사
- `/추리` → 가설 메모
- `/정답` → **최종 추리 제출** (5문항, 최대 3회, 몇 개 맞았는지만 알려 줌). 이름만 맞히면 해결로 인정되지 않음
- `/진행도` → 포인트·진행 상황

## 개막 공지 문안 (운영진이 `/운영 공지` 로 게시)

```
/운영 공지 내용:🌙 도근고등학교 달빛 방송부 추석 특별 방송 ON AIR!\n\n방송 준비 중 예정에 없던 고백이 송출되었습니다. 누가 녹음했고, 누구에게 전하려던 마음이었으며, 누가 방송에 내보냈을까요?\n\n📺 모션 웹툰 12화가 순서대로 이 채널에 공개됩니다.\n❓ /질문 으로 YES/NO 질문을 하고, 🔎 /증거 · /조사 로 단서를 모으세요.\n📝 추리가 완성되면 /정답 으로 최종 추리를 제출! (최대 3회)\n\n지금 /시작 을 입력하거나 아래 [수사 시작하기] 를 눌러 특별 조사원으로 등록하세요.
```

## 이벤트 진행 중

- **00:00 개막**: 봇이 개막 공지(포스터·사건 소개·진행 방법·버튼)와 1화를 게시합니다. 20초 간격 점검이라 최대 20초 늦을 수 있습니다.
- **회차 공개**: 편성 시각마다 자동 게시. 해당 회차에서 열리는 증거는 같은 게시물에 "새 증거 공개" 로 함께 붙습니다.
- **운영 알림**(운영 채널 또는 DM)이 오면 `/운영 상태` 를 보고 아래 표대로 조치합니다.
- 하루 한 번 `/운영 상태` 의 "최근 해석 실패 질문" 을 보고, 자주 나오는 표현을 `questions.json` 의 `accepted_variations` 에 추가한 뒤 봇·API 를 재시작하면 인식률이 올라갑니다. (정답은 `answers.json` 에만 있습니다.)

|---|---|---|
| 영상 파일 누락 | "EP.N 공개 시각이지만 영상 파일/링크가 없습니다" | 파일을 `episodes/` 에 넣거나 `video_url` 입력 → 30분 안이면 자동 게시, 지났으면 `/운영 공개 대상:회차 번호:N` |

| 게시 권한 오류 | "게시 실패: Forbidden/Missing Access" | 이벤트 채널에서 봇 역할 권한(보기·보내기·임베드·첨부·기록 보기) 확인 후 `/운영 공개` |

| 문제 상황으로 잠시 멈춤 | — | `/운영 중지` → 해결 → `/운영 재개` (중지 중 지난 회차는 알림 확인 후 수동 공개) |
| 웹 조사실 접속 불가 | — | `systemctl status dalbit-api dalbit-web`; 디스코드 명령어(`/질문` 등)는 계속 사용 가능 |
| 서버 교체 | — | `bot/var/dalbit.db` 를 새 서버로 복사하면 게시 이력·진행도가 그대로 이어짐 |

## 테스트 시나리오 (별도 테스트 서버에서 리허설)

실서버에 조기 공개하지 않도록, 리허설은 **운영진만 있는 테스트 서버**에서 합니다. 실서버 ID 로는 개막 시각 변경이 거부됩니다.

1. 테스트 서버와 채널을 만들고 봇을 초대합니다.
2. `bot/.env` 를 복사해 테스트용으로 설정:
   ```
   DG_TEST_MODE=true
   DG_TEST_GUILD_ID=<테스트 서버 ID>
   DG_TEST_CHANNEL_ID=<테스트 채널 ID>
   DG_TEST_START_AT=<지금부터 3분 뒤, 예: 2026-09-23 21:30>
   DG_DB_PATH=var/rehearsal.db
   ```
   `settings.json` 편성 시각도 리허설용으로 몇 분 간격으로 채웁니다 (리허설 후 원복!).
3. `python -m bot.main` 실행 후 확인:
   - [ ] 개막 시각 전: 참가자 `/시작` → "이벤트는 … 에 시작됩니다"
   - [ ] 개막 시각: 개막 공지 1회 + 1화 게시 (영상 첨부/링크/누락 보류 동작)
   - [ ] 봇을 껐다 켜기 → 개막 공지·1화가 **다시 올라오지 않음**
   - [ ] [수사 시작하기] → 나에게만 보이는 수사 수첩, 참가 포인트 +10
   - [ ] `/질문 휘혈이는 하늘이를 좋아해?` → 공개 회차 기준 응답, 쿨타임·일일 한도 동작
   - [ ] `/질문 남궁호가 송출하지 않았나요?` → 긍정형으로 다시 물어 달라는 안내
   - [ ] `/증거` → 잠긴 증거는 번호만, `/조사` 자동완성에 공개 증거만 표시
   - [ ] 회차 공개 시 새 증거 알림, [시청 완료] 버튼 포인트 1회만 지급
   - [ ] `/정답` → 3회 제한, "5문항 중 N개" 만 표시, 이름만 맞힌 경우 해결 불인정
   - [ ] 봇을 끈 채 다음 회차 시각을 30분 넘기고 켜기 → 자동 게시 대신 운영 알림
   - [ ] `/운영 중지` 후 참가자 기능 정지 안내, `/운영 재개`
   - [ ] 12화 후 `/운영 공개 대상:엔딩` → 진실 공개 + 정답 보상 정산
   - [ ] `/운영 결과 형식:CSV` 다운로드
   - [ ] 웹 조사실: 로그인(테스트 서버 멤버만), 질문·증거·노트·최종 추리가 디스코드 진행도와 같은지
4. 리허설 후 `DG_TEST_MODE=false`, 테스트 편성 시각 원복, 리허설 DB 삭제 확인 후 실서버용 봇을 실행합니다.

## 자동 테스트

```bash
cd dokeun-motion-webtoon
python -m pytest bot -q
```

질문 해석(동의어·주어 방향·부정형·미공개 차단), 한국 시간 편성, 중복 게시 방지·재시작 복구·재시도, 게임 규칙(쿨타임·한도·보상 1회·정답 채점·제출 제한), 정답 비노출, 웹 API(로그인·잠금·운영진 CSV), 명령어 등록을 검사합니다.
