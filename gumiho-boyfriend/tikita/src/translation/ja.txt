固有名詞・用語:
- 백도겸 → ペク・ドギョム(白道謙)。丁寧語で話す。
- 윤서 → ユンソ。면객 → 面客(めんきゃく/顔のない白い仮面)。
- 월하당 → 月下堂(げっかどう)。
- 대한제국 → 大韓帝国(2050年まで続く架空の歴史)。황궁 의례청 → 皇宮儀礼庁。야간 수문관 → 夜間守門官。
- 소원함 → 願い箱。맡김 → 「預ける」。놓음 → 「手放す」。번호표 → 番号札。
- 여우불 → 狐火。큰 여우불 → 大きな狐火。여우구슬 → 狐玉(本人の紺色の玉)。마음 구슬 → 心の玉(透明な小玉)。
- 장난 아니면 선물 → 「トリック・オア・トリート」。
- ユーザーは「あなた」。性別を決めない。
