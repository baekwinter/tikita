# 캐릭터 외관 설정 — 《내 남자친구는 구미호》

이미지를 만들기 전에 고정해 두는 기준표입니다. 모든 컷은 이 문서를 따릅니다. 이미지 생성 순서는 다음과 같습니다.

1. 맨 아래 **기준 시트 프롬프트**로 인물·소품 시트를 먼저 만듭니다.
2. 마음에 드는 시트를 고르고, 그 이미지를 참조 이미지로 넣어 `tikita/image_prompts.md`의 장면 5장을 만듭니다.

작품이 **전체 이용가**이므로 노출, 유혈, 과한 공포 연출은 쓰지 않습니다.

## 2. 백도겸 — 사람의 모습

### 고정 외형 (모든 컷에서 동일)

| 항목 | 설정 |
|---|---|
| 인상 나이 | 서른 전후. 실제 나이는 밝히지 않음 |
| 키·체형 | 184cm. 마른 듯 단단한 체형, 곧은 어깨, 긴 목. 근육을 과시하지 않음 |
| 피부 | 창백하고 매끈한 도자기 피부. 혈색이 적고 눈 밑에 옅은 그늘 (피로) |
| 얼굴형 | 누가 봐도 미남. 갸름한 V라인, 선명한 턱선, 높고 곧은 콧대, 옅은 장밋빛의 얇은 입술 |
| 눈 | 길고 가는 눈매, 속쌍꺼풀, 눈꼬리가 살짝 내려간 '낮은 눈매'. **눈꼬리에 옅은 홍조**가 번져 아이라인처럼 보인다(여우의 흔적). 아래 속눈썹이 길다. 홍채는 **맑은 푸른색** `#4F7DB8`, 사람의 둥근 동공 |
| 표식 | **왼쪽 눈썹 끝의 아주 작은 점.** 모든 컷에 넣는다 |
| 머리 | 윤기 있는 흑발 `#141216`, 한 올씩 결이 보인다. 오른쪽 7:3 가르마에 흐트러진 앞머리가 한쪽 눈썹과 눈을 살짝 덮는다(식사할 때 귀 뒤로 넘긴다). 옆머리는 귀 윗부분을 덮고, 뒷머리는 목덜미에 닿을 만큼 |
| 손 | 길고 마디가 곧은 손가락. 오른손 중지 첫 마디에 붓 굳은살. 반지 없음 |
| 기본 표정 | 차분한 반쯤의 미소. 웃을 때 **왼쪽 입꼬리가 먼저** 올라간다 |
| 당황할 때 | 시선을 먼저 내리깔고, 손으로 찻잔이나 카드를 만진다 |
| 상징 포즈 | 손바닥을 펴 보이기 (해치지 않는다는 표시), 한 걸음 떨어져 서기, 메뉴판을 상대 쪽으로 밀기 |
| 상시 소품 | 왼손목의 얇은 검은 손목 화면 밴드 |

### 의상 4종 (+ 손상 변형)

**A. 외출복 — 1화 소개팅, 5화 후일담**
- 회색 울 체스터 코트 `#8A8D91`, 무릎 위 길이
- 안에 먹색 개량 저고리. 흰 동정이 아주 얇게 보이고, 먹색의 짧은 옷고름이 있다
- 짙은 차콜 슬랙스, 검은 더비 구두
- 5화 후일담에서는 같은 옷에 손끝이 살짝 푸르스름하다 (여우구슬에 금이 간 뒤라 손이 차다)

**B. 월하당 — 2화, 상담실, 프로필 이미지**
대한제국 개화기 신사의 차림을 2050년식으로 옮겼다. 갓은 쓰지 않는다.
- 검은 개량 두루마기 `#1B1B1F`, 무릎 아래 길이, 소매 폭은 좁게
- 안에 먹색 저고리, 그 위에 **검푸른 양복 조끼**. 조끼 주머니에서 **은 회중시계 줄**이 늘어진다
- 바깥에서는 **검은 펠트 중절모**에 작은 은색 이화(오얏꽃) 핀을 단다. 실내에서는 벗어 탁자 옆에 둔다
- **소매 끝에 먹빛 잉크 얼룩**
- 실내에서는 버선이나 검은 실내화

**C. 안채 — 3화 생활 장면**
- 소매를 팔꿈치까지 걷은 미색 무명 저고리 `#F2EFE8`
- 무릎이 조금 해진 회갈색 바지
- 머리가 평소보다 흐트러지고, 앞머리가 이마에 내려와 있다

**D. 황궁 의례청 야간 수문관 제복 — 3·4·5화 근무, 대표 이미지**
대한제국 문관 대례복을 2050년식으로 옮긴 디자인이다. 황제의 군복이나 대례복이 아니라 관원의 예복 계열이다.
- 검푸른 `#1C2A3A` 울 프록코트. 무릎 위 길이로, 두루마기처럼 곧게 떨어진다
- **무늬 없는 옷감.** 꽃무늬 직물이나 문양 원단을 쓰지 않는다
- **높은 스탠드 칼라.** 칼라와 소매 끝에만 가는 **은사 이화문(오얏꽃) 자수 띠**가 둘린다. 꽃무늬는 이 두 곳과 휘장에만 둔다
- 앞여밈에 은색 이화 단추 한 줄
- 왼쪽 어깨에 짧은 검푸른 망토(케이프)를 걸친다
- 좁은 검정 가죽 허리띠, 이화문을 새긴 작은 은색 버클
- 같은 색 바지, 검정 단화형 부츠
- 왼쪽 가슴에 직원 출입증: 은색 카드에 이화문, 검은 끈. 사적인 자리에서는 옷 안으로 넣는다
- 행사 근무 때는 챙이 짧은 검푸른 **예모**(원통형 정모)에 은색 이화 휘장을 단다
- 금색 자수, 견장의 술 장식, 훈장 다발은 쓰지 않는다. 황제·원수처럼 보이면 안 된다
- **금지:** 용·봉황 문양, 흉배, 붉은 곤룡포, 황색 계열, 왕관과 익선관. 황족처럼 보이면 안 된다

**D′. 그을린 제복 — 4화 23시 이후, 5화**
- 오른쪽 깃과 소매에 푸른 그을음이 남는다. 천은 타서 뚫리지 않고, 은사 자수 일부가 그을음에 녹아 보인다

## 3. 백도겸 — 본모습 (구미호)

**이야기 안에서는** 4화 23시 10분, 첫 큰 여우불과 함께 처음 드러납니다. 그 전의 장면 이미지(갤러리 배경)에는 꼬리를 그리지 않습니다.

**홍보 이미지에서는** 다릅니다. 작품 제목이 이미 '구미호'이고 공모전이 인외 설정을 보기 때문에, 대표 이미지와 프로필에는 구미호다운 매력을 앞에 내세웁니다. 푸른 빛을 내며 은빛 세로 동공으로 갈라지는 오른쪽 눈, 얼굴 곁을 감싸는 흰 꼬리, 손끝의 푸른 여우불 정도입니다. 진짜 반전은 정체가 아니라 그가 숨긴 마음 구슬이므로, 이것으로 스포일러가 되지 않습니다. 꼬리 아홉 개가 다 드러나는 전신 본모습은 비밀 이미지로 아껴 둡니다.

| 항목 | 설정 |
|---|---|
| 눈 | 여우불처럼 **푸른 빛을 내는 홍채** `#5FA8FF`에 가늘게 선 **은빛 세로 동공** `#DDE3EA`. 흰자는 그대로 둔다. 홍보 이미지에서는 **오른쪽 눈만** 변하고 왼쪽은 사람의 푸른 눈으로 남는다 |
| 꼬리 | **정확히 아홉 개.** **새하얀 털** `#FFFFFF`. 끝까지 순백이다. 본모습일 때는 **푸른 여우불이 꼬리와 몸을 휘감아 돈다**. 이름의 백(白)과 이어지는 색이고, 흑발·검푸른 제복과 대비되어 한눈에 구미호로 읽힌다. 한 개의 길이는 약 1.2m로 풍성하고 부드러운 털이다. 허리 뒤의 공간에서 부채꼴로 펼쳐진다 |
| 꼬리가 나는 방식 | 옷을 뚫지 않는다. 등 뒤 그림자에서 피어나듯 생겨난다 |
| 귀 | **사람의 귀 그대로. 여우 귀는 없다** |
| 얼굴·몸 | 그 밖에는 사람의 모습과 같다. 송곳니, 발톱, 털은 생기지 않는다 |
| 분위기 | 위협적이기보다 사람들 앞을 막아서는 울타리처럼 꼬리를 펼친다 |

### 여우불

| 종류 | 모습 |
|---|---|
| 작은 불씨 | 손등이나 손바닥 위의 손톱만 한 청색 불꽃. 흔적을 읽을 때 쓴다 |
| 큰 여우불 ① | 돌바닥에 낮게 깔려 번지는 청백색 불. 탈 속이 비어 있음을 비춘다 |
| 큰 여우불 ② | 도겸의 발밑에서 돌길을 따라 달리는 불줄기. 은색 실을 끊고 그림자를 붙든다 |
| 큰 여우불 ③ | 가슴의 여우구슬에서 끌어낸 불. 굴린 엽전과 문턱 사이에 빛의 경계선을 세운다 |

어떤 불이든 사람이나 옷을 태우지 않습니다. 색은 `#5FA8FF`, 중심부는 `#E8F4FF`입니다.

### 여우구슬 (도겸의 것)
- 지름 약 3cm, 호박알 크기의 **검푸른** `#16324F` 구슬. 안쪽에 별가루 같은 미세한 빛이 떠 있다
- 평소에는 가슴 안에 있어 보이지 않는다. 큰 불을 쓸 때 가슴 중앙에서 옷 위로 검푸른 빛이 비친다
- 셋째 불을 쓸 때는 손바닥 위로 끌어낸다
- **금이 간 뒤:** 표면에 밝은 청색 균열선이 남는다. 다시 붙거나 고쳐진 모습으로 그리지 않는다. 새하얀 꼬리 아홉 개도 끝부터 잿빛으로 바래 한 계절 동안 돌아오지 않는다

## 4. 윤서 — 소개자 (보조 인물)

이미지 기획 10장에는 등장하지 않지만, 장면에 넣을 때를 대비한 기준입니다. 성별은 원고에서 정하지 않았으므로, 아래 외형은 바꿀 수 있는 제안입니다.

| 항목 | 설정 |
|---|---|

| 머리 | 짙은 갈색 단발 웨이브, 한쪽을 귀 뒤로 넘김 |

| 옷 | 바래고 낡은 흰 두루마기 같은 축제 의상. 소매가 손보다 길고, 소매 끝에서 은색 실 몇 가닥이 늘어진다 |

| 첫 햇빛 | 젖은 종이처럼 납작해지며 땅의 이음새로 스며든다 |
| 연출 | 섬뜩하지만 잔혹하지 않게. 피, 상처, 비명은 쓰지 않는다 |

## 6. 당신 (사용자) — 화면에 나오는 방식

- 얼굴, 성별, 체형은 그리지 않는다. **손, 어깨너머 시점, 뒷모습 실루엣, 옆모습 일부**만 쓴다
- 손은 중성적으로 그린다. 반지, 네일, 문신은 넣지 않는다
- 기본 소매는 무채색 니트 소매다. 축제 컷에서는 옷이 보이지 않도록 프레임을 정한다
- 도겸이 당신을 붙잡거나 끌어안는 구도는 쓰지 않는다. 두 사람 사이에 늘 한 뼘의 거리를 둔다

## 7. 소품

| 엽전 | 녹이 살짝 슨 구리 엽전 하나. 3화부터 월하당 문턱 틈에 끼워져 있다 |
| 달·여우 타로 | 남색 뒷면에 은색 초승달과 여우 문양 |
